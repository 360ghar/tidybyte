# macOS Cleaner

<!-- impeccable:product-schema 1 -->

## Platform

Native macOS application, SwiftUI, macOS 26 and later.

## Users and purpose

Mac users need to understand disk use, reclaim space, and organize files. Scanned paths and project context inform proposed actions. Users review and approve actions before execution.

## Capabilities and constraints

Local scanning, file visualizations, duplicate detection, app footprints, cleanup review, storage snapshots, forecasts, reports, and restore history. Optional user-configured AI providers follow explicit privacy settings. Local scanning works without AI. Phase 2 cloud and team features are excluded.

## Product principles

- Show scope and evidence before a decision.
- Keep selection, approval, and execution separate.
- Apply safety checks again at execution.
- Describe recovery per operation; do not promise universal undo.
- Use native Mac navigation, keyboard controls, and accessibility behavior.
